# Markup 语法（Markdown 扩展）

`.md` / `.markdown` 文件是面向写作的文档入口。它兼容标准 CommonMark 与 GFM，并扩展了文档元数据 `@!(...)`、元素属性 `@(...)`、数学公式、WikiLink 以及 `#import` / `#call` 模块调用，最终通过前端无关的 `notist_core::Module` IR 静态检查并求值为一个 `Block`。

## 文档头：元数据与导入

```markdown
@!(title: "入门指南", draft: false)
#import "./components/lib.not" as ui
#import "./helpers.not": badge
```

- `@!(key: value, ...)` 将属性挂到文档根 `Block` 上，常用于设置 `title`、`template` 等站点元数据。
- `#import` 支持与 `.not` 相同的导入形式，行尾分号可选，可出现在文档顶部或正文中。
- 文档顶层保持纯声明式，不允许 `fn`、`let`、`if`、`match` 等控制流语句；所有逻辑与组件定义集中在 `.not` 模块中。

## 块级元素

| 元素 | 写法 | 说明 |
| --- | --- | --- |
| 标题 | `# 一级` .. `###### 六级` | 1–6 级标题，`sectionize()` 会自动折叠为嵌套 `Section` 并将标题属性提升到 `Section` |
| 段落 | 连续非空行 | 以空行分隔不同段落 |
| 无序 / 有序列表 | `- 项`、`* 项`、`1. 项`（保留起始序号如 `3.`） | 支持缩进形成多行块内容与任意层级嵌套列表 |
| 引用块 | `> 引用正文` | 内部可嵌套普通块级元素 |
| 分隔线 | `---` | 3 个及以上连续 `-` / `*` / `_` |
| 表格 | `\| 列1 \| 列2 \|` + `\| :--- \| :---: \| ---: \|` | GFM 管道表格，支持左/中/右列对齐与完整行内语法 |
| 代码块 | 三个反引号加语言名 | 支持 `rust,ignore` 等围栏属性后缀 |
| 块级数学 | `$$ ... $$`（单行或多行围栏） | 产出 `BlockKind::Math` |

## 行内元素

- **粗体**：`**bold**`
- *斜体*：`*emph*` 或 `_emph_`
- ~~删除线~~：`~~strike~~`（代码模式下也可用 `#strike[...]`、`#underline[...]`）
- 行内代码：`` `code` ``
- 行内数学：`$E = mc^2$`
- 链接：`[标签](./other.md#anchor)` 或 WikiLink `[[Target|显示文本]]`
- 图片：`![替代文本](./logo.svg)`

## 属性注解 `@(...)` 与 `@!(...)`

属性注解在解析阶段作为占位节点进入 IR，随后由前端无关的统一 AST pass 挂载到**紧跟在它后面的第一个节点**：

- **文档根属性 `@!(...)`**：挂载到整篇文档根 `Block`，支持标量与圆括号列表值（如 `@!(title: "指南", tags: ("a", "b"))`）。
- **块级属性 `@(...)`**：独占一行（可多行叠加）或紧贴单行 `#expr`，挂载到同一块序列中的下一个块元素（含列表项内的缩进块，如 `- @(collapsed: true)` 换行接 `Group`）。
- **标题属性提升**：写在标题上的 `@(id: "intro", class: "lead")` 在 `sectionize()` 后会提升到外层 `<section id="intro" class="lead">`。
- **行内属性 `@(...)`**：挂载到紧随其后的第一个行内节点（如 `@(class: "key")**重点**`、`@(id: "ref")[链接](./other.md)`，连续软换行文本会先合并为单个文本节点再挂载）。
- 属性值支持 `Bool`、`Int`、`Float`、`String` 及圆括号列表 `()` / `("only",)` / `("a", "b")`。

## 调用函数与内容字面量

在 Markdown 中使用 `#` 调用已导入模块的函数或内置 prelude 函数；紧跟在调用后的 `[...]` 会按位置参数自动追加到参数列表末尾：

```markdown
欢迎使用 #ui.badge("Notist", 1) 与 #strong[静态类型内容]。

#callout("tip")[
  首尾带空白的方括号解析为 `Block`；
  紧贴无空白的方括号 `[inline]` 解析为 `Inline`。
]
```

> 在文档顶层，仅 `#ident(...)` / `#ident[...]` / `#(expr)` 会进入代码调用；普通 `# 标题`、`#hashtag` 与 URL 中的 `#anchor` 均不受影响。在 `.not` 代码的 `[...]` 字面量内，还可直接使用 `#name` / `#a.b` 插入局部变量。
