# S1：markup 全语法 CST

前置：S0 已完成（段落 + heading 全管线可走通）。
目标：draft「语法」节列出的全部 markup 构造都有 CST 表达——`#` 只做到平衡扫描占位、math 只做到 `$..$` 不透明。不含注解、不含 sectionize（S3）、不含 check（P2）。
验收：corpus 全绿；任意用例的 CST 文本拼接 == 源文件（lossless 自检）。

## 工作方式

- 每步只引入一个新概念；完成即提交，仓库保持绿。
- 先写 corpus 用例（`.not` 输入 + 手工预期的树），再实现到 snapshot 匹配。
- 任何"这种情况该怎么办"的瞬间：停下来，把规则用中文写进 draft「语法」节，再实现。文法决策和调试不混在一起。
- 需要的全部前置概念就四个：token 与 node 的区别、peek（看不消费）、stop 条件、lossless（每个 token 必须挂在树上）。遇到了再查。

## 阶段一：不需要 inline 基础设施的热身

### Step 1 — 围栏 raw 块

- 规则：行首 ≥3 个反引号开始，后可跟语言 tag 到行尾；直到行首出现等长或更长的反引号串闭合；内容不透明、原样保留。未闭合：到 EOF 结束 + 诊断。
- 改动：lexer 加 Backtick token；parser 加块级分支；CST 加 Raw 节点。
- 用例：基本围栏、带语言 tag、内容含更短反引号串、未闭合。
- 概念：终结符扫描。

### Step 2 — 注释

- 规则：`//` 到行尾（不含换行）；`/* */` 可嵌套（计数器）。未闭合块注释：到 EOF + 诊断。
- 注释是 trivia：留在 CST，不进 core 树（lower 跳过）。
- 用例：独占一行、行尾注释、嵌套块注释、未闭合。
- 概念：trivia 纪律。

## 阶段二：inline 基础设施（纯重构，snapshot 不变）

### Step 3 — lexer 全量化

- 加 token：`*` `_` `` ` `` `\` `[` `]` `(` `)` `|` `#` `$`（Backtick 已有）；Text 在这些字符前断开。
- 验收：现有 snapshot 一个都不变——token 切细不影响拼接结果，亲眼验证"lexer 细化对上层透明"。

### Step 4 — inline parser 脚手架（全 S1 最重要的一步）

- 引入 Inline 节点；paragraph/heading 把内容交给 `parse_inline(stop)` 消费，初版原样产出、不做任何构造识别——行为保持重构，测试必须全绿。
- lower 改为从 Inline 出发：相邻 Text/Whitespace 合并为一个 text item。
- 概念：递归下降 = 函数调函数；stop 条件是子解析器的契约。
- **完成此步后 review 一次脚手架再往下走**——这里的约定影响后面所有步。

## 阶段三：行内构造（每个都是小递归，按难度排）

### Step 5 — 转义与强制换行

- 规则：`\` + 特殊字符 → 字面字符；`\` + 换行 → hardbreak 节点；`\` + 普通字符 → 原样保留反斜杠。
- 用例：`\*` 不强调、`\[`、行尾 `\`。
- 概念：取消一个 token 的特殊性。

### Step 6 — 行内 raw

- 规则：反引号串开始，等长反引号串闭合；内容不透明；未闭合 → 字面文本。
- 用例：基本、内容含更短串、未闭合。
- 概念：分隔符串长匹配（Step 1 的行内版）。

### Step 7 — strong / emph（S1 最硬的骨头）

- 规则先落 draft：`*…*`、`_…_` 配对；可互相嵌套；找不到闭合符 → 退化为字面文本（绝不 panic、尽量不诊断）。是否允许跨 soft break 配对需一并定。
- 用例：基本、嵌套 `*a _b_ c*`、未闭合、紧邻 `*a**b*`、跨行。
- 概念：配对与递归；resilience 是 parser 的本职。

### Step 8 — math

- 规则：`$…$`，内容不透明；未闭合 → 字面文本。同 Step 6 模式。

### Step 9 — 链接

- 规则：`[[target]]`、`[[target|text]]`、`[text](url)`。见 `[` 时有界向前看：扫到匹配 `]`，其后是 `(` 才按 md 链接解析；否则 wikilink；都不是则字面文本。链接文本区域递归 inline 解析。
- 用例：三种形态、链接文本内含 strong、缺 `(` 按字面、`|` 缺失/多个。
- 概念：有界 lookahead——只看不改，决定后再走。

### Step 10 — `#` 占位

- 规则：`#` 后跟标识符：吃掉标识符 + 紧跟的平衡括号组（可无）；`#` 后跟 `(`/`[`：平衡扫描。产出 CodePlaceholder 节点，内部不求值。
- 用例：`#fn`、`#fn(1, (2))`、`#(a + b)`、未闭合。
- 概念：配对栈。

## 阶段四：块级最难的留最后

### Step 11 — 列表

- 规则先落 draft：`-`/`+` 开头为项；缩进超过 marker 列的续行归属该项；同级 marker 开新项；列表如何结束（空行？dedent？）需定。项内容允许嵌套块（含子列表）。
- 用例：单层、嵌套、项内多行、列表后接段落、`-` 与 `+` 混排。
- 概念：缩进敏感（行首数空格，比想象中简单）。

## 完成定义

draft「语法」节除「暂缓」组外全部构造可解析、可 dump、lossless 自检通过。
