## 实例身份共享

Item.instance 和 Item.target 使用既有 Shared<FunctionInstance>，保持完整函数身份、comptime 参数、target 与语义身份的区分。clone 分享不可变身份；通过 DerefMut 修改时 COW 分离。不缓存求值结果、不合并挂载、不用地址判断语言身份，不修改预算计数。

Rust API 迁移（wire 和 Debug 值不变）：

```rust
item.instance = Some(instance.into());
item.target = Some(target.into());
let borrowed: Option<&FunctionInstance> = item.instance.as_deref();
let owned: Option<FunctionInstance> = item.instance.as_deref().cloned();
// 如需修改，COW 保证其它节点的身份不变。
item.instance.as_mut().unwrap().function.name = "other".into();
```

新增实例／target 共享与独立修改、独立 children 挂载、完整 wire 往返回归。手写 JSON 边界只借用解引用，不强制启用 core serde。
